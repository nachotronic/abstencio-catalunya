# Encargos de ilustraciones

Lista de ilustraciones pendientes para ChatGPT. Cada encargo va por dos sitios a la vez:

1. Un issue de GitHub con la etiqueta `ilustracion`, título «Ilustración: <slug>» y una mención a `@codex` en el cuerpo, para que Codex se ponga solo.
2. Una fila aquí, en «Pendientes», con el número del issue, para la tarea programada de ChatGPT, que lee este fichero cada día.

Quien la haga la entrega en un PR con «Closes #<issue>» en la descripción y, en ese mismo PR, pasa la fila a «Hechos». Si ChatGPT no puede subir la imagen al repositorio, se la da a Nacho, que la deja en el hilo de Claude, y Claude la coloca y cierra el encargo.

Formato de todas: JPG horizontal de 1280 × 720, collage editorial, sin texto incrustado. Ver `AGENTS.md`.
